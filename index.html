使い方のヒント

  • 内容メモには、相手からのメール・打合せメモ・自分の考えをそのまま貼るのがいちばん早いです。整理は資料メーカーがやります。
  • できた資料は「作った資料」から開き、「修正指示」に一言書くと作り直せます（例: 費用の表を削って / もっと柔らかい言い方に）。
  • 企画書・一覧表は HTML と CSS も保存されるので、手で直してから「HTML から PDF を作り直す」もできます。
  • 説明資料の 1 枚だけ気に入らないときは、その枚の「作り直す」で個別に再生成できます。
